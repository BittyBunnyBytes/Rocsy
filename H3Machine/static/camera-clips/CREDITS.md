# Camera move example clips

From the CameraBench test set (Lin, Cen et al., "Towards Understanding Camera
Motions in Any Video", arXiv:2504.15376), https://huggingface.co/datasets/syCen/CameraBench,
licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
Changes: trimmed to at most 4 s, letterbox removed, scaled to 360 px wide,
re-encoded as silent H.264. Built by the session script cam/build.py; `index.json`
lists each chip's source clip id and the dataset's caption for it.
