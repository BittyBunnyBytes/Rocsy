Best settings

Rated setting combos, highest scoring first. Score is the average rating ( 2, 1, −1) with one extra neutral vote, so one lucky render can't beat a combo proven over many. Time is the average render time of its rated videos.

    Hermes prompt refinement

    Enhance sends the Studio prompt as a Hermes refinement task to the selected model in the local Llama service. It includes the additional syntax, H3 guide and example files and waits for the shared GPU queue.

    Hermes model

    The local Llama model that plans, reviews and rewrites prompts for Enhance and Agentic.

    Multi-GPU is a per-model setting: Llama Swap → the model → Parameters → Multi-GPU.

    Available levels depend on the model. Output continues until the model finishes or reaches its context limit.
    Thinking per Agentic stage
    How much text the model can hold at once (prompt + guides + thinking + answer). Default 65536 (64k). A new value reloads the model on the next request; larger values use more VRAM.
    Advanced sampling

    Agentic rendering

    Hermes picks each clip's length and mode itself unless your request says otherwise; presets decide quality and size.

    Used for every final clip, continuations included.
    A fast, low-resolution preset. Clip lengths and references stay as planned.
    0 = review once and keep the result as is. After the last round Agentic keeps the latest version. Default 1.

                Temporal chunking 
                
      
                  
      
                    
      
                  
      
                    
      
                  
      
                    
      
                
      
                
      Lengths are whole 17-frame steps (24 fps, so 136 ≈ 5.7 s). Auto picks the longest chunk that fits the 3D upscaler in about 9 GiB. Anchor strength sets how closely each chunk's first frame follows the previous chunk (0.999 = node default).

      Tiling splits the second pass into smaller pieces. It lowers the DiT's VRAM at large sizes, but the 3D upscaler still runs on whole chunks. Above about 75k tokens per tile the INT8 attention kernels crash. Watch long clips: 15 s renders at 379 frames (past H3's 362-frame max, capped since Sept 30) had tiles come out black or NaN; "Stable (untiled)" is the fallback.
