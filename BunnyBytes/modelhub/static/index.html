How ratings work

        

          
Fits in VRAM runs entirely on the GPU with room to spare (full speed). Fits in VRAM (tight) runs on the GPU, but with little VRAM left: close other GPU apps and big browser tabs first. Loads with base model LoRAs: a small add-on loaded next to its base model.

          
Split across GPUs LLMs only: llama.cpp spreads layers over every GPU.

          
Needs RAM offload / Needs CPU offload bigger than your VRAM: part of it has to live in system RAM (ComfyUI streams it in) or run on the CPU (llama.cpp), which is several times slower. Too big for VRAM + RAM won't load at all. NVIDIA-only format / Apple-only format / Not GGUF (llama.cpp) a file format this machine can't run (NVFP4, MLX, AWQ/GPTQ).

          
★ Best for your hardware marks the highest-quality quant that still fits comfortably.
