What it controls

Schedules

Sends the Master Agent a request at a set time, in a new session. With a run time it keeps working until that time is up. /schedule in the Agent chat does the same.

Permissions

The Master Agent is a full Hermes agent. These decide which of Hermes' tools it may use and how far it may go. Hermes' own hard safety blocks always apply.

Hermes tools

Image search

How the Master Agent looks up reference pictures on the web.

Rules

The briefs and prompts behind the Master Agent and Hermes' dataset work (auto-tag, auto-cut, clip finder). Changes apply to the next run.

Sub-agents

The AI behind every agentic mode: the Master Agent, Video, Image, Music and Voice Agentic, REA and Vibe Coding. Each one keeps its own model, thinking and checks; changes save at once and apply to its next run.

Set them all at once

Gives every sub-agent the same local model and thinking level. Sub-agents that think through Hermes (Master Agent, REA, Vibe Coding) take it when Hermes lists the same model.

Compression

How hard the Master Agent's Hermes sessions shrink their history to fit the model's context. Stronger saves context and prompt-reading time but forgets more detail. Applies within 30 s, from the next model call.

Strength

Summaries

Hermes replaces the older turns with a summary written by the session's own model (nothing else loads into VRAM).

Trimming and cuts

Cheaper than a summary: old tool outputs (terminal, file reads, searches) are cut to a one-line note without a model call. The agent can run the tool again if it needs the output.

Backup model

Placeholder: picking an online model to write summaries when the session's model can't is coming later. For now this list only shows which online models will be available.
