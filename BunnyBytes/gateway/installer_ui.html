Install Rocsy

Six short steps. Nothing changes on this machine until you press Install on the last one.

An internet connection is needed for Docker packages, images and the backends you choose. Models and LoRAs download later, in Models.

Step 1 of 6

Your system

Rocsy runs in Docker. The installer checks what this machine already has and sets up anything missing with your distribution’s package manager (APT, DNF, Zypper, pacman, APK, XBPS, eopkg or Portage).

L

Windows support is untested. Rocsy runs inside WSL2 (Ubuntu) with Docker Engine there. The GPU needs the current AMD Windows driver and AMD’s ROCm for WSL in the distro; GPU tuning and some host features are Linux-only.
