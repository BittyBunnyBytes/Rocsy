Use it in games, Discord and other programs

Easiest: Output → My microphone, press Start, and pick Rocsy Voice as the microphone in the other program (this computer only). Keep this tab open while you talk.

Your own program: Output → 📡 API publishes the converted voice on a channel; connect to the listen URL shown there to receive it live (bots, overlays, game mods, another PC).

Without the browser (Linux): on this PC run python3 BunnyBytes/voice/realtime/rocsy_vc_client.py --voice "Name" --virtual-mic (once: pip install -r BunnyBytes/voice/realtime/requirements-client.txt), then pick Rocsy Voice as the microphone in the game. It never plays through your speakers.

Windows: install a virtual audio cable, pick it under "Play it on" above (or run the client with --output "CABLE Input") and choose the cable as the game's microphone.

Another computer / your own app: WebSocket /Voice/v1/realtime on this site with a key from Llama API → Keys for other apps (tick "Real-time voice conversion"). Send 16-bit mono PCM, get the converted voice back. Details: BunnyBytes/voice/realtime/README.md.

Shortcuts on this tab: M mute, R record. A live session takes a turn in the GPU queue; with jobs running one at a time, renders wait while you talk (Queue → Queue settings → "Run jobs together when they fit").
