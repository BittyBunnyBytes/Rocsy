Reverse Engineer Anything

Look inside any program

Add a game folder or a single file. REA sorts every file, spots the engine, decompiles it, and helps the Master Agent build, test and install mods against the game's own code.

Your games and programs

    How it works

    1. 1AddMount a game folder read-only, or upload a binary, APK or archive.
    2. 2ExploreRanked files, engine detection, a Decompiled explorer with scripts, assets and 3D previews.
    3. 3BuildDescribe a mod or rewrite; the agent plans it, you approve, it builds against the game's code.
    4. 4Test & installHeadless test runs next to the unmodified game, then install and play. Uninstall restores the game.

    What REA can open

    • ▣Games and programs Unity (Mono / IL2CPP), Unreal, Godot, RPG Maker, Ren'Py, Electron and more: every file sorted by what it really is, opened with one click.
    • ⌘Native binaries ELF, PE, Mach-O through Ghidra: functions, pseudocode, assembly, strings, callers, xrefs.
    • ✦Everything else APKs, JS apps, .NET, firmware, captures, websites: ask the Master Agent, which has all 170 REA tools.

    Uploads are saved in the agent's workspace (rea/) so the Master Agent can open them too. Analysis runs on the CPU in the REA container; nothing leaves this computer.

    Logs

    Test runs of this game's mods (build, syntax check, headless run, baseline and engine logs) plus each mod's latest decompile, build and loader logs. Kept until you delete them.

                                                          Test run
                                                          
              
                                                          How test runs work
                                                          Builds the mod, checks its syntax, then runs the game headless (no window, no GPU; works from any device) with the mod loaded for a while, and compares the errors with an unmodified run. With Screenshots on, the game runs on a virtual display instead (software rendering, slower) and REA saves what it shows: startup, the main menu, after a few inputs that usually start the game (Enter, a click, walking), the last frame, and whenever the mod loads or an error appears, next to the same moments without the mod. Leftover game processes are always killed. Logs are kept in the Logs tab.
