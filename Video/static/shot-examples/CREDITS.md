# Shot composition example stills

Middle frames of clips from the CameraBench-Pro test set
(https://huggingface.co/datasets/georgeliu59/CameraBench-Pro), labelled by shot size
and camera angle. It is the follow-up benchmark to CameraBench (Lin, Cen et al.,
arXiv:2504.15376, CC BY 4.0); the Pro repository itself does not state a license.
Changes: one frame per clip, letterbox removed, scaled to 360 px wide.
`index.json` lists each image's source clip id and label category.
